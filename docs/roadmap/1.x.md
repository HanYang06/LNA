# LNA 1.x 路线图（草案）

> **权威顺序 `路线图 > 设计 > 代码`。** 本路线图定「做什么、按哪套设计、落在哪个版本」，
> 设计与代码都往它收；**它不宣布现状**——卡片里的现状转述与代码不符时，改的是本页那一行。
>
> 格式、字段与维护口径见[结构说明](index.md)。分组按[驾驭架构](../architecture/design.md#4-驾驭架构与-a--b--c-的角色已定)
> 的三支柱（调度核心 / 模型 / 训练）＋ 横切基础设施；**序号自上而下严格递增**（见结构说明）。
> 版本号对应[达成路径](../architecture/design.md#5-达成路径已定)的 Phase：`0.1.0` = Phase 1（A / C 往返），
> `0.2.0` = Phase 2（引入 B），`0.3.0` = Phase 3（加宽 B），`1.0.0` = Phase 4（重新聚合）。
