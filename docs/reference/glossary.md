# 术语表

> LNA 的词有**明确所指**，混用会读错设计。这里只收"读了会误解"的词；
> 定义以[设计篇](../architecture/design.md)与代码为准，本表只是索引。
>
> **命名铁律**：一个概念只有一个名字，**以中文为准**——术语本身按中文自然层级来定，
> 英文命名非必需（乐意就加，不乐意就不加）。新增概念**先入表**再进代码与设计；
> 同一概念不得出现第二个名字（别名一律视为错）。

## 顶层

| 词 | 含义 | 不是什么 |
|---|---|---|
| **驾驭架构** | 整套架构的**总名**，核心是「驾驭」；由三支柱（模型 / 调度核心 / 训练）＋横切基础设施（数据 / 监控 / 报告）构成 | 不是某个模块；也不是模型本身 |
| **调度核心** | 驾驭架构的**核心部件**：① 加载模型；② 按数据决定往哪路由（英文落点 `orchestrator/`） | 不是语言本身；不是模型的一部分；也不是某个专家 |
| **模型** | 就是一个**模型**，**角色无关**；A / B / C 由调度核心**运行时分配** | 不是 A / B / C 的某一层；**不写死角色**（写死就没了多模型编排） |

## 编排

| 词 | 含义 | 不是什么 |
|---|---|---|
| **声明** | 调度核心的编排输入：用**普通 Python** 写「哪个层用哪个模型、怎么用、进出什么语言」 | 不是 DSL；**写的时候不执行框架** |
| **生成物** | 声明跑出来的两套文件：**JS**（机器用、不给人看）与 **YML**（人读的加糖描述） | 不是手写文件；也不是 JSON（太啰嗦） |

## 语言

> **内部语言**这一侧。单位按中文自然层级组织：**词 → 词序列 → …**，
> 更长的组合"自然而然就有名字"，不硬造。

| 词 | 含义 | 不是什么 |
|---|---|---|
| **词** | 内部语言的**最小单位** = ID + 向量 | 不是"字"；也不是没有 ID 的裸向量 |
| **词序列** | **连续的词**组成的序列（一段内部码） | 不是词表；也不等于令牌序列 |
| **内部语言** | 模型与模型之间的私有语言，是本框架成立的前提；封闭、可版本化 | 不是自然语言；也不是某一模态的方言 |
| **词表** | 全部「词」的集合：**全局唯一、共享、外部**；像 **tokenizer** 一样伴随训练全程；它本身就是语言版本号 | 不是每个模型各有一份；**「冻结」指固化后的版本**，不是训练时 |
| **ID** | 词里**离散、封闭、固定宽度**的那一半：寻址 / 版本 / 路由；基础锁定、增量向后扩展 | 不是可训练参数 |
| **向量载体** | 词里**可微**的那一半——纯 ID 不可导，梯度传不过去 | 不是模型自有的嵌入空间（它属于全局唯一的共享词表） |
| **双向奔赴** | 模型与**共享词表互相塑造**——含义不是随机向量自带的，也不是单向「模型适应表」，而是双方共同长出来；N 个模型一起注入即**多向奔赴** | 不是单向适应；防漂移靠**唯一一份 ＋ 门控 ＋ 版本**，不靠冻结 |
| **幽灵模型** | 对**词表**的一个**视角**：它有参数、挨梯度、被优化，像一个模型，却**没有自己的前向**，只活在别的模型引用它的时候——「在训练一个不存在的模型」即指此 | **是比喻、不是新实体**；也不是真正的模型（模型 = 参数 ＋ 结构 ＋ 前向） |
| **内部码** | 一段外部输入经 A 编码出的**词序列** | 不是矩阵 / 张量本身 |
| **换能器** | 外界的语言 / 模态 ⇄ 内部语言的翻译器，即 **A / C** | 不是专家；不产生新语义 |

## 训练与验证

| 词 | 含义 | 不是什么 |
|---|---|---|
| **专家** | **B 层的独立小模型**；B 是 N 个专家（不是一个网络），只讲内部语言 | 不是单体大模型；不是一个共享权重的网络 |
| **编码坍缩** | 退化成**平凡双射查表**（token X → 向量 Y → token X）：用了词表却没造出语言 | 不是训练 loss 不降（loss 可以很低而照样坍缩） |
| **三重门控** | 防坍缩的三道控制：编码长度调控、信息熵、组合性探针 | 不是优化器的一部分；是"从生成侧打分" |
| **编码长度调控** | 内部码长度不能顶格、也不能极致压缩，压到合理阈值 | 不是越短越好 |
| **信息熵门控** | 不算熵必然坍缩（熵正则，防码本 / 后验塌缩） | 不是 reward |
| **组合性探针** | 防**整体式编码**：每个输入各给一个不可拆的码（熵漂亮、长度合理，但零可重组） | 不是长度或熵的检查——它专门查"子段能否重组" |
| **坍缩检测** | 换一批**没见过**的文本对，看往返一致性是否立刻崩 | 不是训练集上的准确率 |
| **往返一致性** | 文本 → A → 内部码 → C → 文本，还原文本与原文本的吻合度 | 不是 A / C 各自的准确率 |
| **泛化阈值** | 把"新角色学习难度"操作化为**达到 X% 往返一致率所需的梯度步数** | 不是最终准确率 |
| **扩圈** | 迭代学习：从 A / C 二人对练起步，逐步引入新角色 | 不是一次性全量开炼 |
| **梯度下降分析** | 对**词表**做的分析：不硬逼梯度下降，但看它对梯度有没有表现——据此判断向量**真的带有含义，还是假的** | 不是"必须训练词表"；也不是训练模型本身 |

## 工程

| 词 | 含义 | 不是什么 |
|---|---|---|
| **A / B / C** | **调度核心分配的三个角色**：A / C 为**对外换能器**（初期同构、未来不同构），B 为**专家集合** | **不是模型的层**，不写进模型代码——模型是角色无关的 |
| **权威顺序 `路线图 > 设计 > 代码`** | 路线图管「做什么、落在哪个版本」，设计管「为什么」，代码管「现在是什么」 | 不是三层平级（冲突时改下层） |
| **记忆** | `.agents/skills/memory/`：**决策**（一主题一文件、只写现状态）与**进度**（只记未做） | 不是变更流水账；不留归档 |
| **路线ID** | 路线图条目的三位序号（`001`…），全局唯一、只增不减、号不复用 | 不是 issue 编号 |
